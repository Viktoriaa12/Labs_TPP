
# Projectile Motion Simulation

## Опис проєкту

Проєкт створено в межах лабораторної роботи № 5.
Програма моделює рух снаряда під дією сили тяжіння
та графічно відображає його траєкторію.

Реалізація виконана мовою C++ з використанням
бібліотеки SFML 3 та системи збирання CMake.

## Можливості програми

- Візуалізація траєкторії руху снаряда.
- Зміна початкової швидкості.
- Зміна кута запуску.
- Обчислення часу польоту.
- Обчислення дальності польоту.
- Обчислення максимальної висоти.
- Запуск, пауза та скидання симуляції.

## Фізична модель

У програмі використовується модель руху без опору повітря.
Прискорення вільного падіння становить 9.81 м/с².
Передбачається, що снаряд приземляється на ту саму висоту,
з якої його було запущено.

Час польоту:

T = 2v₀ sin(θ) / g

Дальність польоту:

L = v₀² sin(2θ) / g

Максимальна висота:

H = v₀² sin²(θ) / (2g)

## Керування

- Стрілка вгору — збільшити швидкість.
- Стрілка вниз — зменшити швидкість.
- Стрілка вправо — збільшити кут запуску.
- Стрілка вліво — зменшити кут запуску.
- Space — запустити політ або поставити його на паузу.
- R — скинути поточний політ.

## Збирання проєкту

1. Встановити Visual Studio з компонентом
   Desktop development with C++.
2. Встановити Git та vcpkg.
3. Клонувати цей репозиторій.
4. Переконатися, що vcpkg доступний за шляхом
   C:/vcpkg, або змінити шлях у командах нижче.
5. У корені проєкту виконати:

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Debug
```

Залежність SFML задається у файлі vcpkg.json
і встановлюється під час конфігурації CMake.

## Запуск

Після успішного збирання у Windows можна запустити:

```powershell
.\build\Debug\ProjectileMotion.exe
```
