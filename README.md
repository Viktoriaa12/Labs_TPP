# Statistical Analysis Library

## Опис проєкту

Проєкт містить статичну бібліотеку `StatisticalSample` для роботи з числовими вибірками та виконання базового статистичного аналізу.

Бібліотека підтримує:
- додавання одного або декількох елементів;
- очищення вибірки;
- обчислення середнього арифметичного;
- обчислення медіани;
- обчислення вибіркової дисперсії;
- обчислення стандартного відхилення;
- обчислення квартилів.

Для обробки помилок реалізовано власну ієрархію винятків на основі `std::runtime_error`. Також використовується клас `ScopeLogger`, який демонструє роботу RAII та фіксує вхід і вихід із функцій.

## Структура проєкту

- `include/` — заголовкові файли бібліотеки.
- `src/` — реалізація бібліотеки.
- `demo/` — демонстраційна програма.
- `tests/` — автоматизовані тести Google Test.
- `exceptions_demo/` — демонстрація роботи з різними типами винятків.
- `CMakeLists.txt` — конфігурація збирання проєкту.
- `vcpkg.json` — опис залежностей проєкту.
